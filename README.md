# Simple Spam Filter with Neural Network

A machine learning project that detects spam messages using a neural network built with TensorFlow and Keras.

## 🚀 Features
- **High Accuracy**: Achieves ~98% accuracy on SMS spam dataset
- **Deep Learning**: Uses Embedding layers and GRU architecture
- **Real-time Prediction**: Classifies new messages instantly
- **Clean Code**: Well-documented and easy to understand
